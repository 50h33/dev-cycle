# /wrap-up - 로컬 세션 요약

현재 대화, Git 상태와 실제 검증 기록을 근거로 세션을 요약한다. 외부 서비스로 전송하지 않는다.

## 사실 수집

- `dev-cycle.config.json`의 저장소 설정과 `artifactsDir`
- 현재 브랜치, 작업 트리, diff와 최근 커밋
- 이 세션에서 실제로 끝난 일과 실패 또는 미실행 검증
- dev-cycle CLI 실행 기록이 있다면 그 기록. `PreToolUse` 호출 로그는 완료 증거로 쓰지 않는다.

## 출력

- 한 일
- 주요 결정과 근거
- 변경과 커밋
- 검증 결과: 성공, 실패, 중단, 생략, 미실행을 구분
- 다음 할 일과 미해결 사항

확인되지 않은 결과를 보완하거나 Slack, Notion, GitHub로 전송하지 않는다. report 기능이 아직 구현되지 않았으면 Markdown 초안이 CLI 산출물인 것처럼 표시하지 않는다.

# /review-pr - 원격 PR 리뷰 제안

`$ARGUMENTS`의 PR을 읽고 리뷰 코멘트 제안만 만든다. 직접 게시하려면 사용자의 요청 범위에 코멘트 게시가 포함돼 있어야 한다.

1. `dev-cycle.config.json`에서 `repository`와 `paths.conventions`를 읽는다.
2. PR 제목, 본문, head SHA와 diff를 조회한다.
3. 코멘트 위치는 diff 표시를 그대로 믿지 않고 PR head의 실제 파일과 대조한다.
4. 저장소 지침을 기준으로 정확성, 설계, 오류 처리, 보안, 성능과 테스트를 검토한다.
5. 번호, Must/Should/Nit, 파일과 실제 위치, 근거, 개선 방향으로 제안한다. 코드 예시보다 문제와 검토 방향을 설명한다.
6. 사용자가 게시할 항목을 이미 지정했다면 지정 범위만 게시한다. 지정하지 않았다면 제안 목록에서 멈춘다.

리뷰를 위해 fetch가 필요하면 먼저 작업 트리를 확인하고 사용자 변경을 보존한다. 임의 체크아웃이나 파일 수정은 하지 않는다.

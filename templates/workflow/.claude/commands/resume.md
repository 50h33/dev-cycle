# /resume - 세션 재개 오리엔테이션

작업 메모와 Git 상태를 읽어 현재 위치와 다음 작업 하나를 제안한다. 코드, 커밋과 브랜치를 변경하지 않는다.

1. `dev-cycle.config.json`과 `paths.conventions`를 읽는다.
2. `.claude/claude-progress.txt`와 `.claude/feature_list.json`이 있으면 읽는다. 없으면 예제 위치만 안내하며 직접 만들지 않는다.
3. 현재 브랜치, 작업 트리, 기준 ref와 최근 커밋을 확인한다.
4. 메모의 내용이 Git과 이슈 상태에 맞는지 대조한다. 오래되거나 충돌하면 신뢰하지 않는다.
5. doing 항목을 우선하고 없으면 todo 항목에서 다음 작업 하나를 제안한다.

메모는 개인 보조 자료이며 승인, 테스트 성공 또는 공유 상태의 기준이 아니다. 실제 구현은 사용자가 요청한 범위에서 `/dev-cycle`로 이어간다.
